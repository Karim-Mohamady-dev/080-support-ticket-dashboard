# Helpdesk — لوحة تذاكر الدعم (080)

لوحة دعم ثنائية اللغة (العربية RTL والإنجليزية LTR) مع مبدّل لغة محفوظ في localStorage.

## المزايا
- إنشاء تذاكر مع تحقق من الحقول (موضوع وبريد ووصف)
- بحث ومرشحات حسب الحالة والأولوية والوكيل
- تفاصيل تذكرة مع رسائل وردود، وتغيير الحالة والأولوية والتعيين
- إحصاءات حسب الحالة، وحفظ كل شيء في localStorage

## التشغيل
```bash
npm install
npm run dev
npm run build
```
